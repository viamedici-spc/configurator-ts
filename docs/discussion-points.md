# Discussion points

What is undecided. A decision moves to *Resolved* with a link to where it is recorded.

## Open

### The generator for the engine client

`src/apiClient/engine/Engine.ts` is generated by swagger-typescript-api from the engine's OpenAPI document
(`scripts/swaggerGeneration.mjs`). Alternatives today generate types only (openapi-typescript with openapi-fetch) or a
function SDK (@hey-api/openapi-ts). A types-only client would need no generated runtime code and fit the toolchain
better; switching touches `src/domain/EngineApiClient.ts`, `src/domain/logic/EngineLogic.ts` and the mappers. Also
open: whether the generator script moves into a `scripts/` package of its own, in TypeScript.

### fp-ts and morphic-ts

Both are in maintenance (fp-ts) or unmaintained (morphic-ts). Whether to keep them, move to Effect, or drop an FP
library is open; the public typings already depend on neither's internals.
